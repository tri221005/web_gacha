Kết nối hosting live

Web không dùng file trên máy bạn. Nó gọi API panel PikaMC để đọc AuthMe và Coin trên server đang chạy.

  1. Vào hub.pikamc.vn và đăng nhập tài khoản hosting.
  2. Mở Tài khoản → API Keys → Create.
  3. Đặt tên jellyvale-gacha. Để trống IP (hoặc chỉ IP máy chạy web).
  4. Bật quyền server: files.read-content, files.query-raw, và control.console (để trừ/cộng Coin khi quay). Không bật power, files.update, files.delete.
  5. Lưu rồi copy key ngay (panel chỉ hiện một lần).
  6. Mở file E:\code\log\web-gacha\.env, dán: 
    PIKA_BASE_URL=https://hub.pikamc.vn
PIKA_API_KEY=dan-key-vao-day
PIKA_SERVER_UUID=
PIKA_AUTHME_DB=/plugins/AuthMe/authme.db
PIKA_ECONOMY_DB=/plugins/ExcellentEconomy/data.db
  7. Nếu có nhiều server, copy UUID trên URL panel (/server/xxxxxxxx-....) vào PIKA_SERVER_UUID. Để trống thì web lấy server đầu tiên.
  8. Chạy lại start.bat rồi bấm nút test bên dưới.
